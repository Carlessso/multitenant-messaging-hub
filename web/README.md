# Messaging Hub web UI

React + Vite + TypeScript UI for the messaging hub. See the [root README](../README.md#web-ui) for how to run it.

```bash
npm install
npm run dev      # http://127.0.0.1:5173, proxies the API on 127.0.0.1:3000
npm run lint     # oxlint
npm run build    # type check + production build
```
